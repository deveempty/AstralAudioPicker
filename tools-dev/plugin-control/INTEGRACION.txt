USO Y PERFIL
La nueva seccion Plugin contiene los controles por grupos y los botones Restaurar estandar / Recuperar mis ajustes.
Estandar v1 es una base inicial, no un ajuste auditivo universal:
- V3 actual ON; Loudness EQ / Footstep / LUFS ON.
- Pasos +12 dB, sensibilidad 45%, graves +6 dB, agudos +2 dB, mezcla 100%, refuerzo enemigo +2 dB, ambiente V3 80%, salida 0 dB.
- Disparos ON: volumen 18%, sensibilidad 62%, release 121.9 ms, AI 72%.
- Ambiente nuevo ON: reduccion -3 dB, detector 70..1800 Hz.
- Compresor OFF.
Los cambios del Picker y del editor del DLL se comparten y persisten. Restaurar estandar archiva los ajustes personales para recuperarlos.
Sin archivo compartido, el DLL conserva el funcionamiento local de REVAMP 03 y sus valores iniciales anteriores. No impone el estandar hasta que se crea el perfil desde el Picker.

CONTRATO
Ruta de produccion: %ProgramData%\AstralAudio\Control\v3\profile.json.
Directorio de pruebas: variable ASTRAL_PLUGIN_CONTROL_DIR, usada solo en procesos de prueba.
Schema astral-plugin-v3; stateVersion 3; standardVersion 1; 50 valores normalizados y revision monotona.
El Picker crea el perfil al abrir su seccion Plugin. El plugin consulta el archivo desde un hilo de control independiente, cada 50 ms.
Los sliders del Picker agrupan escrituras; la respuesta es eventual, no automatizacion sample-accurate. Puede tardar unas decimas de segundo en reflejarse el estado visual.
Bloqueo entre procesos y reemplazo atomico; se mezclan cambios por parametro. Si dos interfaces cambian el mismo parametro a la vez, gana el ultimo cambio escrito.
Una vez conectado, el perfil compartido tiene prioridad sobre los chunks guardados por APO; los sliders locales del plugin siguen funcionando en ambos sentidos. Para importar un preset antiguo al control compartido habria que implementar una accion explicita de importacion.
El indicador de audio exige un heartbeat reciente de una instancia que realmente haya ejecutado processBlock con la revision recibida. Una instancia de editor sin audio no se presenta como motor de audio conectado.
El indicador no certifica que el dispositivo este enrutado correctamente ni que el usuario oiga sonido.
